# LiveWhisper

Traduzione live per la lezione. Sopra, in piccolo, quello che viene trascritto. Sotto, in grande, la traduzione.

Apri la pagina in Chrome o Edge, poi:

```bash
npm install
npm run dev
```

Vai su `http://localhost:5173`. Premi **Ascolta** e consenti il microfono. Spazio avvia e ferma. **Intero** e **Pulisci schermo** servono quando proietti.

Il motore **Automatico** usa la traduzione sul dispositivo di Chrome, quando c’è. La prima volta scarica un modello. Finché non è pronto, le frasi passano da MyMemory. DeepL si attiva solo se lo scegli e incolli una chiave API: resta nel browser e il server locale la inoltra.
